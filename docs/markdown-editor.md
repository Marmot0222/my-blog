# Markdown 创作与阅读

后台仍使用原生 textarea；工具栏对当前选区执行原生 insertText 编辑事务，保留浏览器撤销栈、普通 Tab/Enter 和文本粘贴。桌面可编辑/预览/分屏，窄屏用编辑/预览切换，切换不卸载输入框。

选择文件、拖放和编辑框内粘贴共用串行队列。只接收实际 File，不抓取剪贴板 HTML；混合粘贴先插入纯文本，再按文件顺序建立唯一锚点。拖放使用编辑框最后的选区位置。上传完成只替换仍存在且唯一的锚点，删除锚点、取消、卸载会取消任务。不会用捕获的旧正文覆盖新输入。失败保留本地 File 供重试，最多 10 项/合计 50MiB，刷新不能恢复文件。没有虚假的百分比。

上传前/中可以补充图片说明。最终插入稳定 `/media/<uuid>` Markdown；说明中的括号和反斜线转义。不使用 object URL。未完成上传阻止发布；保存草稿只提交去掉占位的正文，失败文件不被声称已保存。新建草稿保存导航后未完成上传将取消，可从媒体库找回已经成功的孤立上传。

未保存预览使用 Server Action 返回 RSC 内容，可保留共享代码复制/图片 Dialog 客户端岛，不使用第二套 HTML 或 Markdown 解析器。Action 校验管理员、Origin、字段/大小及全局频率，编译并发 1；不保存 revision、不创建任务。700ms debounce，AbortController/序号丢弃旧响应；AbortController 仅取消结果应用，不宣称能取消服务端编译。pending 保留上一版，错误可以刷新重试。管理响应不进入公开缓存。

公开详情、AI 文章抽屉、已保存及未保存预览共用 `compileMdxContent`、Shiki 主题和阅读组件。代码栏独立于横向滚动区，复制源码而非高亮 HTML，只有 Clipboard 成功才反馈成功。受管图片按服务元数据预留尺寸，首图 eager、其余 lazy；点击使用共享 Radix Dialog，Escape 关闭并无滚动恢复焦点，链接中的图片保留原链接行为。
